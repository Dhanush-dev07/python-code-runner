# Python Code Evaluation Engine

A lightweight Python code execution engine built using subprocess isolation and timeout guards.

## Features
- **Subprocess Isolation**: Runs student/external code safely in a separate process.
- **Timeout Protection**: Automatically kills processes exceeding 2 seconds to prevent infinite loops.
- **Output Capture**: Captures standard output (`stdout`) cleanly for downstream evaluation.
